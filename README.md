## Install

No install needed — run everything through [uvx](https://docs.astral.sh/uv/):

```bash
uvx cc-transcript --help
```

`uvx` fetches cc-transcript into a throwaway environment and runs it. To add it
to a project instead:

```bash
uv add cc-transcript
```
